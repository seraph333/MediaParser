# 短视频/图集解析插件

## 简介

短视频/图集解析插件（支持抖音、快手），通过配置的接口解析内容并发送到微信

## 安装

将插件文件夹复制到 xxxbot 的 `plugins` 目录下。 

## 配置
```
[MediaParser]
enable = true
video_api_url = "https://www.hhlqilongzhu.cn/api/sp_jx/sp.php?url=" #主接口，不支持图集
api_url = "https://api.dudunas.top/api/qushuiyin/?AppSecret=123&text="#备用接口，支持视频&图集，每天有次数限制
api_timeout = 5 # API解析专用超时时间(秒)，建议设置短一些
max_retries = 1  # 最大重试次数
max_video_size = 30  # 单位MB，30MB为宜，实测太大发不出
```
## 使用方法

发送抖音/快手链接给机器人即可
